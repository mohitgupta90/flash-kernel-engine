FlashKernel-Engine

CUDA 12.x • C++17 • WebGPU (WGSL) • GLSL • MIT License

View on GitHub

Standard attention implementations materialize an $O(N^2)$ attention matrix in global memory (HBM), creating a severe memory-bandwidth bottleneck. FlashKernel-Engine breaks this bound by holding intermediate blocks in fast on-chip SRAM, updating statistics incrementally via Online Softmax, and utilizing vectorized 128-bit memory instructions.

⚡ Tiled FlashAttention-2

Implements Tri Dao's online softmax formulation with query/key-value SRAM tiling, padded strides to eliminate 32-way bank conflicts, and causal autoregressive masking.

🎯 Tensor Core WMMA

Leverages nvcuda::wmma 16x16x16 FP16 matrix multiplication fragments targeting Volta through Hopper architectures for peak arithmetic throughput.

🔄 Fused RMSNorm & SwiGLU

Single-pass sum-of-squares warp reduction and 128-bit float4 loads/stores, outperforming PyTorch eager execution by up to 3.8x.

🌐 WebGPU & GLSL Shaders

Cross-platform compute shaders (WGSL / GLSL 4.50) with workgroup shared memory for high-performance edge and in-browser inference.

Memory Hierarchy & SRAM Tiling Architecture:
